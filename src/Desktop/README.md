# GameNet Manager Desktop

Native Windows desktop application for Operator/Admin.

Technology boundary:
- WPF on .NET 10.
- No browser runtime.
- No embedded web UI.
- No direct database access.
- Communicates with GameNet.Server through versioned API/contracts.
- Persian (fa-IR) and English (en-US) are first-class UI cultures.
- Right-to-left flow is selected for Persian; left-to-right for English.

No business feature belongs in this project until Foundation certification is complete.
